# AI Story Studio

A mobile-friendly, static first version of a personal story-to-video planning website.

## Features
- Bengali/Hindi/English story input
- 5- or 10-minute planning target
- Cartoon, anime, cinematic, realistic and fantasy style labels
- Scene breakdown
- Browser text-to-speech where supported
- Download scene script as a text file

## Deploy with GitHub Pages
1. Upload `index.html`, `style.css`, and `app.js` to the repository root.
2. Open repository **Settings → Pages**.
3. Under Build and deployment choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for the Pages URL to appear.

## Important limitation
This is the first front-end version. It does not yet generate AI images or video clips, nor merge audio/video. Those require a backend or external AI services, which may have free quotas, usage limits, or costs. Do not put API keys in this public repository.
